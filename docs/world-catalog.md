## 来源与筛选

使用 [TheMealDB 官方 API](https://www.themealdb.com/api.php) 的公开开发测试接口，在本机开发项目中获取。查询 a—z 首字母接口后，从 790 条记录中人工选取；按 `strCountry` 核对国家，避免混用不一致的 `strArea` 字段。遵守[来源使用条款](https://www.themealdb.com/terms_of_use.php)，保留 TheMealDB 及贡献者署名、每道菜的来源链接与 API 提供的原作者链接。未抓取网站页面来批量取菜谱。

`server/src/seed/data/world-recipes.json` 保存整理结果；ID 的 `WORLD_` 后缀对应 TheMealDB ID，照片取自同条记录的 `strMealThumb`，按最长边 800px、JPEG 质量 85 缩小，本地共约 19.1 MB。`world-cuisines.json` 保存新增分类。图片不是 AI 生成或 UI 插画。家庭改编版本按来源所属国家组织，不声称所有配方都是唯一传统做法。

候选 175 条中排除 7 条：53068、52782 的标题与做法不符；52978 缺少核心烹饪步骤；52927 的复杂腌制做法缺少对应专用盐用量；53025、53108、52827 的图片与配方明显不匹配。另将春卷、饺子、馅饼等中文名称按实际用料／做法修正。168 张图片均通过联系表人工检查。
