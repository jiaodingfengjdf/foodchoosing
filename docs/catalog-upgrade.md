# 菜库与转盘升级 · 2026-09-21

## 用户可见变化

- 菜库从 55 道扩充为 201 道；149 道附有来源可追溯的菜图。
- 36 个有菜品的风味分类，增加湘、鲁、闽、徽、苏、浙、东北、新疆、陕西、广西、贵州等地方菜，以及更多国际家庭料理。
- 图鉴支持菜名和食材搜索、地区和时间筛选、有实拍筛选、已做／没做／收藏筛选、分页、直接收藏和查看做法。
- 徽章从 8 枚扩充到 20 枚；环球徽章的条件改为当前菜库实际覆盖的四个洲，避免无法达成。
- 中心按钮使用固定居中容器，按压缩放不再覆盖定位；初次进入显示 8 个带名字的候选扇区。
- 等新请求完成后才开始转动，慢网不再播放上次结果；连点有保护，连续抽菜尽量避开上一道，失败重转不扣次数。

## 内容来源

新增 146 道社区菜谱来自 [HowToCook](https://github.com/Anduin2017/HowToCook)，固定版本 `c2063eb7050bac0cb998779c62fa08c649c9882f`。原项目采用 Unlicense，许可副本见 `docs/licenses/HowToCook-UNLICENSE.txt`。

`server/src/seed/data/community-recipes.json` 保存提取后的做法、原配方份量和每道菜的固定版本来源链接；`photo-sources.json` 保存图片来源。图片缩小至最长边 800px，以 JPEG 随项目本地提供，总计约 12 MB。逐图检查后将若干原料／过程图片替换为同一菜谱的成品图；没有合适成品图的条目显示「实拍待补充」，不用其他菜的图片冒充。

原有菜谱仍保留一人份做法；社区配方保留原始人数和用量说明，未擅自改成一人份。来源中的时间和热量为参考值。没有明确地方归属的普通家常菜归入「家常菜 · 不限地区」，不强行标成某个省的代表菜。

## 数据升级与验证

数据库新增 `recipes.metadata` 字段，菜谱按 ID 更新，不删除重建表，也不替换用户的收藏、打卡和照片。原有 55 个菜谱 ID 保持稳定。

回归覆盖菜库完整性与本地图片存在性、搜索分页、地区子树、用户筛选隔离、重复导入保留用户记录、重转失败回滚和转盘扇区角度。真实 Chromium 另外检查不同屏幕宽度的按钮中心位置、按压前后位置、慢网二次转动、真实照片加载、图鉴搜索与收藏。

仍有 52 道菜未配成品照片。离线能力仍以已加载页面和缓存候选为基础，不包含 Service Worker 离线页面包。
